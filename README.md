# 🚀 RojgarSetu - Daily Wage Worker & Contractor Platform

A clean, minimalist standalone presentation hub for **RojgarSetu** designed to connect daily wage workers and contractors directly without middlemen.

It requires **no backend, no database setup, and no server**. Double-click `index.html` to run it directly in modern browsers.

---

## 📋 Core Capabilities & Role Flows

1. **Role-Based Logins (Daily Wage User vs. Contractor)**:
   - Click the **"Switch Role"** button in the top navbar or alert banner to open the login modal.
   - **Daily Wage User (Ramesh Kumar)**:
     - Check, search, and filter nearby daily job openings with live wage rates (`₹900/day`, `₹850/day`, etc.).
     - View full job specifications, timings, locations, and apply or call contractors directly.
     - Access worker profile, rating (`4.94 ★`), credentials, and verified employer reviews via the hamburger menu.
   - **Contractor (Rajesh Sharma - BuildWell)**:
     - Dedicated **"Post a Job"** capability with modal form (title, trade category, day rate, duration, site location, workers needed).
     - New job postings immediately appear in the live feed with active count updates.
     - View contractor company profile and worker ratings in the hamburger menu.

2. **Self-Contained Hamburger Menu (`☰`)**:
   - Slides in cleanly without leading outside the page.
   - Dynamically reflects the logged-in role (Worker vs. Contractor).
   - Preserves verified **Employer & Employee Reviews** (Prestige Home Renovations, BuildWell Infrastructure, Anand Murthy).

3. **Dual Theme Architecture & Instant Dark / Light Mode**:
   - Palette Selector in top navbar: **Emerald Green & Crisp White** (Default) or **Warm Earth & Soft Beige**.
   - Instant Dark/Light Mode toggle with sun/moon icon sync and persistent state across reloads.

4. **Zero Wallet Dependency**:
   - Complete removal of wallet modules, balances, ledger tables, and withdrawal systems.
